\doxysubsection{Detailed Description}
Representa a transferência de valor entre dois Sistemas. 


\begin{DoxyItemize}
\item O \doxylink{class_fluxo}{Fluxo} conecta um sistema de origem a um sistema de destino e utiliza uma equação (função) para determinar quanto deve ser transferido a cada passo de tempo. 
\end{DoxyItemize}
